# ВИДЕО ДЛЯ HERO-БЛОКА

Эта папка предназначена для видео-фона на главной странице.

## Как подключить видео

1. Положи MP4-файл в эту папку, например `hero.mp4`
2. Открой `data.js`, найди строку:

   ```js
   heroVideo: '',
   ```

3. Подставь путь к файлу:

   ```js
   heroVideo: 'assets/videos/hero.mp4',
   ```

4. Залей файлы → видео сразу начнёт играть в hero вместо карусели фото.

## Рекомендуемые параметры видео

- **Формат:** MP4 (кодек H.264) — поддерживается во всех браузерах
- **Разрешение:** 1920×1080 (Full HD) или 1280×720 (HD)
- **Длительность:** 10–30 секунд (видео зацикливается автоматически)
- **Битрейт:** 2–5 Мбит/с
- **Размер файла:** до 5 МБ (важно для скорости загрузки сайта)
- **Звук:** ОБЯЗАТЕЛЬНО убрать звуковую дорожку (видео всё равно проигрывается без звука)
- **Соотношение сторон:** 16:9 (горизонтальное)

## Как ужать видео если оно слишком тяжёлое

Если файл больше 5 МБ — используй любой онлайн-конвертер:
- https://www.freeconvert.com/video-compressor
- https://www.veed.io/tools/video-compressor

Параметры:
- Resolution: 1080p или 720p
- Quality: Medium-High (60-70%)
- Audio: Remove (без звука)

## Как работает на разных устройствах

- **Десктоп / планшет:** показывается видео
- **Мобильный (≤768px):** показывается фото из карусели вместо видео (видео тяжёлое для мобильного трафика)

Если хочешь показывать видео и на мобильном — открой `styles.css`,
найди блок `.hero-video` и удали `@media` правило ниже него.

## Как вернуть карусель фото

Просто очисти поле в `data.js`:

```js
heroVideo: '',
```

Видео автоматически отключится и заработает старая карусель.
