# Medeu Hotel — сайт

Сайт гостиничного комплекса Medeu в Костанае. Чистая статика — HTML, CSS, JS. Без сборки, без npm, без фреймворков. Просто открываешь `index.html` или кидаешь файлы на любой хостинг — работает.

## Структура

```
medeu-site/
├── index.html       весь HTML
├── styles.css       стили
├── script.js        логика: роутинг, темы, карусели, lazy-load
├── data.js          контент: фото, цены, контакты
├── i18n.js          переводы RU / KZ / EN
├── 404.html         страница ошибки
├── sitemap.xml      карта для поисковиков
├── robots.txt
└── assets/
    ├── photos/
    │   ├── home/         фасад (4 фото)
    │   ├── rooms/        номера по категориям
    │   ├── restaurant/   заведения + hero страницы Гастрономия
    │   └── banquet/      банкетный зал + конференц-зал
    ├── payments/         SVG логотипов платёжных систем
    ├── videos/           hero-видео (опционально)
    ├── logo.png
    ├── og-image.jpg
    └── favicon-32.png
```

## Где что править

- **Контент карточек** (цены, фото, телефоны) — `data.js`
- **Все видимые на сайте тексты** (заголовки, описания, кнопки) — `i18n.js`. Сайт всегда подгружает версию языка из i18n, поэтому именно там «правда»
- **Стили** — `styles.css`. Темы реализованы через CSS-переменные (`--c-bg`, `--c-text` и т.д.) и класс `theme-light` / `theme-dark` на `<html>`
- **Логику не трогать** без необходимости

## Замена фото в карточке номера

Каждый номер в `data.js` хранит:
- `image` — главное фото (используется как fallback)
- `images: []` — массив для карусели в карточке

```js
{
  name: 'Стандарт',
  area: '27',
  price: '28 000 ₸',
  image: 'assets/photos/rooms/standard-2.webp',
  images: [
    'assets/photos/rooms/standard-2.webp',
    'assets/photos/rooms/standard-1.webp',
    'assets/photos/rooms/standard-3.webp',
  ],
}
```

Добавить новое фото — кидаю файл в нужную папку, добавляю путь в массив. Карусель подхватит сама. Если в массиве одна картинка — точки и стрелки скрываются автоматически.

## Замена цены и описания

- **Цена** — `data.js`, поле `price`
- **Описание** — `i18n.js`, под ключом вида `rooms.standard_desc` отдельно для `ru` / `kz` / `en`. Сайт показывает версию из i18n. В `data.js` описание тоже продублировано (фоллбек) — менять лучше в обоих местах, чтобы код был согласован

## Изображения

Все фото — WebP, заранее сжаты:
- Hero фасада: 1536×1024, ~200 КБ
- Номера: 1600×1066, 80–150 КБ
- Иконки платёжек: SVG, под 10 КБ каждая

Никаких 4K и тяжёлых PNG в репозитории нет. Если приходят свежие фото от заказчика — конвертирую через [Squoosh](https://squoosh.app) или `cwebp` с качеством 80–85.

## Темы

Светлая и тёмная. Переключатель в шапке (иконка луны/солнца). Сохраняется в `localStorage`. Если у пользователя в системе тёмная тема — она применяется по умолчанию через `prefers-color-scheme`.

## Языки

Три языка: русский, казахский, английский. Переключатель в шапке. Все строки в `i18n.js`. Применяется через атрибуты `data-i18n="ключ"` на элементах.

Чтобы добавить новый ключ — добавляешь его во все три языковых блока (`ru`, `kz`, `en`) и навешиваешь `data-i18n` на нужный элемент.

## Локальный запуск

Двойной клик по `index.html` — работает. Только некоторые fetch-вызовы (например, прогрев фото через `Image()`) могут вести себя по-другому, поэтому для полноценного теста лучше через локальный сервер:

```bash
python3 -m http.server 8000
# или
npx serve
```

## Технические заметки

- **Lazy-load** — фоновые картинки рендерятся через `IntersectionObserver`, грузятся когда блок входит в viewport (запас 200px). Первый экран отдаётся за пару сотен миллисекунд
- **Карусели** — общий рендер для номеров, заведений и конференц-зала. Стрелки + точки + свайп пальцем на мобильных. Авто-прокрутка только на hero страницы Гастрономия (каждые 6 секунд)
- **NBSP** — в денежных значениях (`5\u00A0000 ₸`) и временах (`07:30\u00A0–\u00A001:00`) стоят неразрывные пробелы, чтобы не переносились
- **Шрифты** — Cinzel (логотип), Cormorant Garamond (заголовки), Jost (текст). Google Fonts с `display=swap`, шрифты грузятся параллельно с HTML
- **SEO** — JSON-LD `Hotel` schema, canonical, OpenGraph, Twitter Cards. Sitemap и robots.txt — для индексации
- **A11y** — `aria-label` на интерактивных элементах, `prefers-reduced-motion` отключает анимации, скип-линки (если включены)
