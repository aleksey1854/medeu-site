# MEDEU Hotel — сайт

Сайт гостиничного комплекса «Медеу» в Костанае.

**Технологии:** статика — HTML + CSS + JavaScript. Без сборки, без зависимостей. Достаточно открыть `index.html` или развернуть на любом хостинге, который умеет отдавать файлы.

---

## Структура проекта

```
medeu-site/
├── index.html       — главный HTML со всеми страницами
├── styles.css       — стили
├── script.js        — поведение (роутинг, тема, карусели, ленивая загрузка)
├── data.js          — ВСЕ ДАННЫЕ САЙТА: фото, цены, тексты, контакты
├── .nojekyll        — отключает Jekyll-обработку GitHub Pages
├── .gitignore       — список игнорируемых файлов
└── README.md        — этот файл
```

**Правило:** контент меняется только через `data.js`. Никакой основной код трогать не нужно.

## Как обновить фото и тексты

Открываешь `data.js`, меняешь URL или текст в нужном массиве, сохраняешь, коммитишь, пушишь.

Например, чтобы поменять фото первого слайда на главной:

```js
heroSlides: [
  'https://i.ibb.co.com/НОВЫЙ_URL.jpg',  // <-- сюда
  ...
]
```

Чтобы поменять цену или описание номера — правишь объект в массиве `rooms`:

```js
rooms: [
  {
    name: 'Стандарт',
    area: '18 м²',
    price: '25 000 ₸',   // <-- сюда
    description: 'Уютный номер...',
    image: 'URL'
  },
  ...
]
```

## Оптимизация изображений

Текущие плейсхолдеры — это Unsplash CDN с параметрами `?w=1920&q=80&auto=format&fit=crop`. Они автоматически отдаются как WebP браузерам, которые его поддерживают, и сжаты до качества 80.

**Когда придут реальные фото:**

### Вариант 1 — ibb.co (рекомендую)

Заказчик уже использует ibb.co — это бесплатный image-CDN, фото сжаты на их стороне. Просто заменяешь URL в `data.js` на прямые ссылки `https://i.ibb.co/...`.

### Вариант 2 — локальные файлы

Если хочешь хостить фото в репозитории — обязательно сожми их перед коммитом. Иначе репо распухнет до гигабайт. Используй:

- [Squoosh](https://squoosh.app) — онлайн-конвертер от Google
- [TinyPNG](https://tinypng.com) — сжатие PNG/JPG
- Конвертируй в WebP — занимает в 2-4 раза меньше места без потери качества

**Размеры для разных мест:**
- Hero-карусели — 1920×1080
- Карточки номеров и заведений — 1600×1066
- Карточки на главной — 1200×1500
- Превью / маленькие — 800×600

Никогда не вставляй оригинальные 4К-фото на 5+ МБ каждое — это и есть та проблема с медленной загрузкой.

## Локальный запуск

Просто открой `index.html` в браузере двойным кликом.

Если нужно проверить с локальным сервером (для тестов SPA-роутинга):

**Через Python:**
```bash
python3 -m http.server 8000
```
Открыть `http://localhost:8000`

**Через Node.js:**
```bash
npx serve
```

## Деплой на GitHub Pages

### Шаг 1. Создать репозиторий

1. Зайти на [github.com](https://github.com), нажать «New repository»
2. Имя — например `medeu-site` или `medeuhotel-kz`
3. Public (для бесплатного GitHub Pages)
4. Не отмечай «Initialize with README» — у нас уже есть свой
5. «Create repository»

### Шаг 2. Залить файлы

Из терминала в папке с проектом:

```bash
git init
git add .
git commit -m "Initial commit: Medeu hotel site v1.0"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

### Шаг 3. Включить GitHub Pages

1. В репозитории зайти в **Settings** → **Pages**
2. Source: «Deploy from a branch»
3. Branch: `main`, папка: `/ (root)`
4. Save

GitHub соберёт сайт за 1-2 минуты и выдаст URL вида:
`https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`

Эту ссылку можно отправить заказчику для тестирования.

### Шаг 4. Обновления

После любых правок:
```bash
git add .
git commit -m "Описание правок"
git push
```
GitHub Pages подтянет изменения автоматически за минуту-две.

## Технические заметки

- **Тёмная/светлая тема** — переключается через CSS-переменные и класс `theme-light`/`theme-dark` на `<html>`. Выбор сохраняется в `localStorage`.
- **Lazy loading** — все фоновые картинки грузятся через IntersectionObserver, когда блок попадает в viewport (с запасом 200px). Первая загрузка отдаёт только то, что в первом экране.
- **SPA-роутинг** — без перезагрузки страницы, через `#hash` (например `index.html#rooms`). Удобно — можно скинуть прямую ссылку на любой раздел.
- **Шрифты** — Cinzel (логотип), Cormorant Garamond (заголовки), Jost (тело). Все через Google Fonts с `display=swap`.
- **Accessibility** — `aria-label` на всех интерактивных элементах, `prefers-reduced-motion` отключает анимации для пользователей с настройками доступности.
